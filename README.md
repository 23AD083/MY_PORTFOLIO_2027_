# MY_PORTFOLIO_2027_
# 🌐 Naviya Dharshini | Full Stack Developer Portfolio

A visually rich and interactive developer portfolio built using **React.js**, **Tailwind CSS**, and **Framer Motion** — designed to showcase full-stack development skills, technical experience, and dynamic project presentations.

## ✨ Features

- ⚛️ Built with React.js (Next.js Ready)
- 🎨 Styled using Tailwind CSS with custom themes
- 🌙 Light/Dark Mode Toggle
- 💼 Experience Timeline with animations
- 🖼️ AI-Generated Project Thumbnails
- 🧠 Skill Highlights with hover effects
- 🔁 Responsive & Mobile-First Design
- 🚀 Deployed with Vercel & GitHub Actions
- 🔗 Linked with GitHub & LinkedIn

## 🛠️ Tech Stack

- **Frontend**: React.js, Tailwind CSS, Framer Motion
- **Backend (optional projects)**: Node.js, Express.js
- **Database (for future integration)**: MongoDB
- **Tools**: GitHub, Vercel, Postman, Figma

## 🧪 Highlights

- Built responsive MERN stack apps with JWT auth, boosting user engagement
- Used Tailwind & Framer Motion for smooth UI/UX
- Added AI-generated illustrations for modern appeal
- Integrated CI/CD pipeline with GitHub Actions
